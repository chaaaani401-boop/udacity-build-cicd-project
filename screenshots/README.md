# Submission Screenshots Directory

Place the required submission screenshots here before submitting to Udacity:

1. `frontend_application.png` - Screenshot of working Frontend Application (browser address bar showing URL must be visible).
2. `backend_api.png` - Screenshot of working Backend Application / API (`/api/movies` with browser address bar showing URL must be visible).
3. `kubectl_get_all.png` - Screenshot of `kubectl get all` terminal output (showing pods running and LoadBalancer services with external hostnames).
4. *(Recommended)* `github_actions_workflows.png` - Screenshot of the GitHub Actions tab showing all 4 workflows with green passing checkmarks.
